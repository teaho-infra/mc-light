# Monitor-Side XIAO Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current desktop-base STL generator with a monitor-side square case for Seeed XIAO RP2040, including a flat multi-color translucent red/yellow front cover.

**Architecture:** Keep `hardware/generate_m_shell.py` as the single CAD generator and expose small pure functions for dimensions, McDonald's-style M geometry, back shell, front red area, front yellow M area, and assembly previews. Add Python tests that inspect mesh bounds, watertightness, and color-part alignment without needing a slicer. Export split STL files so multi-color slicers can merge the red and yellow front cover parts into one flush front face.

**Tech Stack:** Python 3, `trimesh`, `shapely`, `numpy`, pytest.

## Global Constraints

- 方形盒体,适合用双面胶贴在显示器右边框或右侧背面。
- 容纳 Seeed XIAO RP2040,板子固定后 USB-C 端朝下。
- 底部开口允许 USB-C 插头从下往上插入。
- 前盖使用多色打印形成红色背景和黄色 M,两者都尽可能薄以便透光。
- 前盖正面平整,黄色 M 不做凸起装饰。
- 红色前盖和黄色 M 都透光。
- 前盖厚度目标 `1.0-1.5 mm`。
- 不做桌面底座。
- 不做外接灯珠、焊接结构或额外电路。
- 不做螺丝固定;优先使用压合、卡扣或少量胶合。
- 输出 `mc_light_monitor_back.stl`, `mc_light_monitor_front_red.stl`, `mc_light_monitor_front_M.stl`, `mc_light_monitor_front_assembled.stl`, and `mc_light_monitor_assembled.stl`.

- [ ] **Step 3: Add M and front-cover builders**

Add these functions after the helpers:

```python
def m_polygon(width=M_WIDTH):
    """返回居中的麦当劳风格 M 填充多边形,位于 XY 平面。"""
    arch_r = width / 4.0
    leg_h = LEG_H * (width / M_WIDTH)
    cx1 = arch_r
    cx2 = width - arch_r
    xs = np.linspace(0.0, width, CURVE_STEPS)
    h1 = np.sqrt(np.clip(arch_r**2 - (xs - cx1) ** 2, 0, None))
    h2 = np.sqrt(np.clip(arch_r**2 - (xs - cx2) ** 2, 0, None))
    top = leg_h + np.maximum(h1, h2)
    pts = [(0.0, 0.0)]
    pts += [(float(x), float(y)) for x, y in zip(xs, top)]
    pts += [(width, 0.0)]
    poly = Polygon(pts)
    return shp_translate(poly, xoff=-width / 2.0, yoff=-poly.bounds[3] / 2.0)


def build_front_parts():
    """返回红色背景区域和黄色 M 区域;两者 z 范围完全一致,正面齐平。"""
    face = shp_box(-BOX_W / 2.0, -BOX_H / 2.0, BOX_W / 2.0, BOX_H / 2.0)
    m_mark = m_polygon()
    red_area = face.difference(m_mark)

    red = trimesh.creation.extrude_polygon(red_area, height=FRONT_T)
    yellow = trimesh.creation.extrude_polygon(m_mark, height=FRONT_T)
    return red, yellow


def build_front_assembled():
    red, yellow = build_front_parts()
    return trimesh.util.concatenate([red, yellow])
```

```python
def build_back_shell():
    """后壳:背面平整,正面开口,底部 USB-C 开口,内部有 XIAO 限位结构。"""
    outer = make_box([BOX_W, BOX_H, BACK_D], [0, 0, BACK_D / 2.0])
    inner = make_box(
        [BOX_W - 2 * WALL_T, BOX_H - 2 * WALL_T, BACK_D - WALL_T],
        [0, 0, WALL_T + (BACK_D - WALL_T) / 2.0],
    )
    usb_cut = make_box(
        [USB_OPEN_W, WALL_T * 3.0, USB_OPEN_H],
        [0, -BOX_H / 2.0, USB_OPEN_H / 2.0],
    )
    shell = trimesh.boolean.difference([outer, inner, usb_cut], engine=ENGINE)

    rail_y_gap = BOARD_POCKET_W / 2.0 + BOARD_RAIL_T / 2.0
    rail_z = WALL_T + BOARD_POCKET_H / 2.0
    left_rail = make_box(
        [BOARD_RAIL_T, BOARD_POCKET_H, BOARD_RAIL_H],
        [-rail_y_gap, 0, rail_z],
    )
    right_rail = make_box(
        [BOARD_RAIL_T, BOARD_POCKET_H, BOARD_RAIL_H],
        [rail_y_gap, 0, rail_z],
    )
    bottom_stop = make_box(
        [BOARD_POCKET_W + 2 * BOARD_RAIL_T, BOARD_RAIL_T, BOARD_RAIL_H],
        [0, -BOARD_POCKET_H / 2.0, rail_z],
    )
    return trimesh.util.concatenate([shell, left_rail, right_rail, bottom_stop])
```

During implementation, orient dimensions so global `X` is left-right, `Y` is vertical on the displayed face, and `Z` is depth from front to back. The bottom USB opening is at negative `Y`.
